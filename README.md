 💜 El duelo y la muerte: un proceso del desarrollo humano

Juego educativo interactivo que permite repasar y aprender sobre el duelo y la muerte en las diferentes etapas del desarrollo humano.

## 🌸 Contenido del juego

El juego contiene 14 preguntas de selección múltiple, organizadas en el siguiente orden:

1. Comprender el duelo.
2. Duelo en la niñez.
3. Duelo en la adolescencia.
4. Duelo en la adultez.
5. Duelo en la vejez.
6. Duelo y tecnología.
7. Duelo y migración.

## ✨ Características

- Cuatro opciones de respuesta por pregunta.
- Una única respuesta correcta.
- 10 puntos por cada respuesta acertada.
- Retroalimentación inmediata.
- Indicador de progreso, puntaje y aciertos.
- Resumen final con porcentaje y revisión de respuestas.
- Se gana al obtener **más del 65 %** de respuestas correctas.
- Interfaz colorida, amigable y animada.

## 🛠️ Tecnologías utilizadas

- Python
- Streamlit

## 📁 Archivos del repositorio

- `app_desafio_duelo.py`: código principal del juego.
- `requirements.txt`: dependencias necesarias para ejecutarlo.

## ▶️ Ejecutar en local

1. Clona o descarga este repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Instala las dependencias:

```bash
pip install -r requirements.txt
```

4. Inicia la aplicación:

```bash
streamlit run app_desafio_duelo.py
```

## ☁️ Publicar en Streamlit Community Cloud

1. Sube los archivos del proyecto a un repositorio de GitHub.
2. Entra a [Streamlit Community Cloud](https://share.streamlit.io/).
3. Selecciona **Create app**.
4. Elige el repositorio y la rama `main`.
5. En **Main file path**, escribe `app_desafio_duelo.py`.
6. Pulsa **Deploy**.

## 💜 Propósito

Promover el aprendizaje y la reflexión sobre los procesos de duelo desde una experiencia interactiva, educativa y respetuosa.
